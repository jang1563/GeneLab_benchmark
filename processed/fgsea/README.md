# fGSEA outputs — sign convention

**All NES/ES values in this directory are FLIGHT-POSITIVE:**
positive NES = pathway upregulated in Space Flight relative to the ground/control
group. This matches the convention of the raw GeneLab `Stat_`/`Log2fc_` columns
as used elsewhere in this repo and of `processed/J2_dge_comparison/`.

Generated by `scripts/run_fgsea.R` from GeneLab DESeq2 DGE tables
(Wald statistic ranking, MSigDB Hallmark/KEGG/Reactome/C2:CGP/C5:GO:BP +
MitoCarta3.0 gene sets).

## Convention change on 2026-08-14

Files generated **before 2026-08-14** used the opposite, ground-control-first
convention (positive NES = up in ground control, i.e. down in flight).
`scripts/run_fgsea.R` deliberately normalized the ranking to the
`Stat_(GC)v(FLT)` contrast direction; this was inconsistent with the
flight-positive `J2_dge_comparison/` files and the raw GeneLab stats, and it
silently inverted every downstream flight-vs-ground comparison
(verified example: liver RR-9 `HALLMARK_OXIDATIVE_PHOSPHORYLATION` had
NES = −2.65 while the same genes had positive mean DGE stat, i.e. up in flight).

On 2026-08-14 the script was fixed to enforce a flight-positive ranking
(prefer the FLT-first `Stat_` column — GeneLab tables ship both directions of
each contrast, so this is an exact mirror of the same comparison — and negate
GC-first stats when no mirror exists), and **all files in this directory were
regenerated**. Consequences:

- `ES` is exactly sign-flipped relative to pre-2026-08-14 files; `NES` is
  sign-flipped up to small fGSEA Monte-Carlo noise in the normalization.
- `pval`, `padj`, `size`, and `leadingEdge_str` gene sets are unchanged
  (p-values vary slightly because fGSEA multilevel is stochastic and unseeded).
- Cross-mission NES Spearman correlations (`summary/nes_correlation_*`) are
  invariant under the uniform flip; they were regenerated from the new files.

**If you consumed pre-2026-08-14 copies of these files** (e.g. external
validation pipelines that correlated these NES against their own
flight-positive signatures), re-pull the files or multiply the old NES by −1.
The AWG Otsuka KMP project's GeneLab validation (script 14) is a known
consumer of the old GC-first files; its script 15 already detects contrast
direction independently and was unaffected.

## Ranking-direction provenance columns (added 2026-08-14)

Each row now records how its ranking vector was built
(`ranking = rank_sign × DGE[[contrast_column]]`):

| column | meaning |
|---|---|
| `contrast_column` | the `Stat_`/`Log2fc_` column of the GeneLab DGE table used for ranking |
| `rank_sign` | +1 if the column is already FLT-first, −1 if a GC-first column was negated |
| `sign_convention` | constant `flight_positive` |

## File-level notes

- `eye/OSD-397_*`: mission label for GLDS-397 (dir `TBD` in `data/mouse/eye/`).
  Stale `eye/TBD_*` files from an older mission naming were removed on
  2026-08-14 (superseded by `OSD-397_*`, which now covers all six DBs).
- `thymus/MHU-1_*` and `thymus/MHU-2_*` both derive from the same GLDS-289
  DGE table and the same auto-detected contrast — check `contrast_column`
  before treating them as independent missions.
- `gastrocnemius/RR-5`: no GeneLab DGE file available, so no fGSEA output.

## Regeneration command

```
Rscript scripts/run_fgsea.R --all-tissues --db hallmark,kegg,reactome,c2cgp,c5bp,mitocarta
python scripts/preprocess_pathways.py --mode conservation --tissue <tissue> --db hallmark
```

# Visual methods-bridge purpose drift check

Date: 2026-06-02

## Anchor

This checks whether the recent BioVis/source-proof work has drifted away from
the original v1-v9 presentation/manuscript plan and the v9 purpose guardrails.

Recent commits reviewed:

- `3c4e97c Add audience organoid matrix proof`
- `7271fe4 Add audience OSD-120 split proof`
- `f90f1f2 Add OSDR source record proof panels`
- `b57c2dc Add local source proof crops`
- `448ef5e Add source object replacement inventory`

## Verdict

No fatal purpose drift.

The recent work is aligned with the visual-premiumization plan if it remains a
methods-bridge and evidence-layer sprint. It strengthens the deck's ability to
show how source records become local task/matrix objects.

Current risk is moderate narrative/sequence drift, not scientific drift:

- OSD-120 and human organoid visuals could become too prominent relative to the
  v1-v7 benchmark result core.
- Proof-object generation could continue indefinitely instead of moving into
  slide-deck assembly.
- Dark slide scenes for extension proofs could make draft v9 extension lanes
  look like finalized benchmark results unless slide placement and captions are
  controlled.

## Alignment With Original Plan

### v1-v9 master outline

Aligned:

- v1-v7 remain the completed benchmark result core.
- v8 remains hypothesis-generation/translation, not a validated
  countermeasure result.
- v9 remains the platform/provenance layer with extension lanes.
- Organoid, multispecies, and single-cell are still framed as extension tracks,
  not primary leaderboard claims.

Watch-out:

- The recent work focuses heavily on OSD-120 and organoids. They should support
  slides 20-22 or appendix/reviewer material, not displace the core slides on
  tissue hierarchy, pathway rescue, model comparison, and v9 platform status.

### v9 purpose drift audit

Aligned:

- OSD-120 is still described as same-study / diagnostic / not
  mission-held-out.
- Human organoid work is still draft/pilot and not mission-held-out.
- Official source pages and local proof objects strengthen the
  provenance-first promise.
- No DOI, release, leaderboard, or final benchmark claim was introduced.

Watch-out:

- The old audit said not to continue open-ended OSD-120 chains. The current
  visual pass is acceptable because it is packaging existing evidence, not
  expanding OSD-120 analysis. It should now stop at shortlist/slide placement.

### visual premiumization plan

Aligned:

- The recent panels follow the rule:
  "Layered PNG scene + editable scientific interpretation."
- Raw low-quality figure/card-box issues were addressed by source-proof crops,
  z-stack/depth, visual QA, and audience-facing wording.
- Internal terms were moved from visible figure text to manifests/docs.
- Tables and detailed decision rows are not being disguised as main figures.

Watch-out:

- Final deck should rebuild Z3-Z5 text, arrows, and captions as editable slide
  objects. The current PNGs are strong evidence scenes, not the final deck by
  themselves.

## Drift Control Decision

Stop generating new OSD-120/organoid proof variants unless a slide-level QA
failure requires a targeted fix.

Next work should be:

1. Create a methods-bridge shortlist/contact sheet.
2. Classify each candidate as main-deck, appendix, or reviewer backup.
3. Place only one organoid bridge and at most one multispecies/OSD-120 bridge
   into the deck outline.
4. Return to the v1-v9 deck spine:
   - v1-v7 result core,
   - v8 hypothesis-only incubator,
   - v9 platform/provenance layer,
   - extension lanes with explicit draft boundaries.

## Bottom Line

The recent work has reduced visual and trust-layer risk, but it should now be
treated as complete enough for shortlist placement. Continuing to generate more
proof panels would become drift. Moving into deck assembly and slide-level
classification is the correct recentering move.

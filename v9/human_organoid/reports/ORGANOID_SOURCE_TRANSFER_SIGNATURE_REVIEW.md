- https://academic.oup.com/stcltm/article/13/12/1186/7833382

NASA OSDR describes GeneLab/OSDR as a curated, standardized, multi-omics space

- https://science.nasa.gov/biological-physical/data/osdr/

For leakage policy, the relevant ML rule remains split-first, train-only model
fitting. scikit-learn's official common-pitfalls guidance warns that test data
must not influence transformations or model-building steps:

- https://scikit-learn.org/stable/common_pitfalls.html#data-leakage

For signature-scoring context, the Connectivity Map/LINCS literature supports
the general practice of comparing biological states by gene-expression
signatures, but this v9 organoid metric remains much narrower: it compares
predicted source-transfer log2FC signs and ranks to the derived OSDR DE
reference.

- Subramanian et al. 2017, Cell:

## Leakage Review

The source-transfer adapter remains acceptable as the first real diagnostic
signature baseline.

Generation rule:

- OSD-863 target contrasts are predicted from OSD-871 training samples.
- OSD-871 target contrasts are predicted from OSD-863 training samples.
- The derived DE reference is not used during signature generation.
- Target-source expression rows are not used during signature generation.
- The generated rows record
  `reference_usage_policy=reference_not_used_for_signature_generation`.

The report contains two source-transfer folds:

| Target Source | Training Source | Train Ground | Train LEO/ISS | Target Contrasts |
|---|---|---:|---:|---:|
| OSD-863 | OSD-871 | 12 | 11 | 4 |
| OSD-871 | OSD-863 | 10 | 9 | 4 |

This is intentionally conservative. Because source, organoid fate, donor block,
and disease context are coupled, a source-local empirical signature would be
too close to reconstructing the reference from the scored source.

## Sign-Imbalance Stress Check

The aggregate direction score is not explained by a trivial positive/negative
majority sign rule.

| Comparator | Aggregate Direction Match |
|---|---:|
| Source-transfer actual | 0.770673 |
| Expected if predicted/reference signs were independent | 0.501897 |
| Always positive | 0.434356 |
| Always negative | 0.565644 |
| Per-contrast majority-sign oracle | 0.576300 |

The actual source-transfer score exceeds the per-contrast majority-sign oracle
by about 0.194. That supports keeping this as a real diagnostic baseline rather
than dismissing it as sign imbalance.

## Join And Identifier Review

All response rows joined by Ensembl ID. This is acceptable for the current
adapter because the normalized expression matrices are Ensembl-keyed and the
response rows intentionally leave `gene_symbol` blank.

However, the report also shows 70,104 duplicate primary gene-symbol keys in the
reference. Future model submissions should prefer Ensembl IDs as the stable
join key, and the scorer should continue to report primary/fallback join counts.

## Biological Interpretation Boundary

The source-transfer baseline should be described as:

> A conservative, non-leaky diagnostic showing that a global LEO/ISS-minus-Ground
> expression signature learned from one human neural organoid source preserves
> some DE directionality when transferred to the other organoid source.

It should not be described as:

- a leaderboard score;
- a proof that cortical and dopaminergic organoids share the same spaceflight
  biology;
- a disease-specific PPMS or Parkinson disease model;
- a microglia-specific response model;
- a validated human CNS spaceflight biomarker model.

## Adapter Decision

Keep `organoid_source_transfer_empirical_signature` as the first conservative
response-signature diagnostic baseline.

Do not promote it to a primary metric or leaderboard result.

The next adapter should be a comparative diagnostic, not a replacement:

1. Per-condition source-transfer empirical signatures.
2. Classifier-coefficient signature diagnostic.
3. Optional top-k/up-down set overlap scorer after the first two are stable.

## Recommended Next Block

`V9-ORG-020: Human organoid per-condition source-transfer adapter design`

Goal:

Design a second response-signature adapter that tests whether matching
microglia condition, disease/control context, or both within the training source
improves target-source DE direction and rank diagnostics without using target
source expression or DE references.

Required leakage boundaries:

- Use training-source samples only.
- Do not use target-source expression rows.
- Do not use OSDR DE tables or the derived DE reference during signature
  generation.
- Treat missing matched training strata as explicit skips, not implicit global
  fallbacks unless the fallback is separately labeled.

Candidate outputs:

- `v9/human_organoid/reports/ORGANOID_PER_CONDITION_SIGNATURE_ADAPTER_DESIGN.md`
- optional follow-up implementation under
  `v9/human_organoid/reports/per_condition_source_transfer_signature/`

## Final Decision

`V9-ORG-019` confirms that the current source-transfer response-signature
baseline is worth keeping as the first conservative diagnostic. Its direction
score is stronger than trivial sign baselines, while its weak rank correlation
correctly limits the claim. The next work should compare it against a
condition-aware train-source adapter before considering more complex model
signatures.
